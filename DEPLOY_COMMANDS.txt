# DEPLOYMENT COMMANDS

## Step 1: Commit and Push Changes

```bash
git add .
git commit -m "Add diagnostic hiring funnel with AI-powered drop-off analysis"
git push origin main
```

## Step 2: Backend (Railway Auto-Deploys)

Railway will automatically detect and deploy your backend changes.

**Verify:**
```bash
curl https://your-backend-url.railway.app/api/health
```

## Step 3: Frontend Deployment

### Option A: Netlify
```bash
cd frontend
npm run build
netlify deploy --prod --dir=dist
```

### Option B: Vercel
```bash
cd frontend
vercel --prod
```

### Option C: Local Test First
```bash
# Terminal 1 - Backend
cd backend
uvicorn app.main:app --reload

# Terminal 2 - Frontend
cd frontend
npm run dev
```

## Done! 🚀

Check your deployed app and verify the diagnostic funnel appears on the Dashboard.
