🔧 SETUP (2 MINUTES):

   1️⃣  Get FREE API Key
       → Go to: https://console.groq.com
       → Sign up (Google/GitHub)
       → Click "API Keys" → "Create API Key"
       → Copy key (starts with gsk_...)

   2️⃣  Add to Backend
       → Open: backend/.env
       → Update:

   3️⃣  Restart Backend
       → Stop server (Ctrl+C)
       → Start: uvicorn app.main:app --reload --port 8000

   4️⃣  Test It
       → Run: python backend/test_groq.py
       → Should see: ✅ SUCCESS! Groq API is working!
